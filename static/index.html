Configuração necessária — arquivo de dados não encontrado

Esse painel lê o histórico de partidas de um arquivo CSV baixado da Oracle's Elixir — assim ele funciona 100% local, sem depender de internet nem de limites de requisição.

  1. Acesse oracleselixir.com/tools/downloads
  2. Clique no link azul "Google Drive" no fim da página
  3. Baixe o CSV do ano que você quer analisar (ex: 2026)
  4. Salve o arquivo na pasta do app como data/oracles_elixir.csv
  5. Clique no botão abaixo (não precisa reiniciar o app)

Busca direto na API pública que o lolesports.com usa — precisa de internet aqui (diferente do resto do site, que é 100% local). Se um jogo não aparecer, é porque não tem partida oficial rolando nesse momento, ou a API mudou de formato do lado deles.

Dados de Valorant não encontrados

Essa aba lê o dataset "Valorant Champion Tour Data" do Kaggle. Baixe em kaggle.com/datasets/ryanluong1/valorant-champion-tour-2021-2023-data (precisa de conta gratuita), extraia o zip, e coloque as pastas vct_2025, vct_2026 etc. dentro de data/valorant/ (assim: data/valorant/vct_2026/matches/overview.csv).

Stats ao vivo (importado de arquivo)

Lê direto de um arquivo que você mesmo atualiza (ex: exportado do vlr.gg) em data/valorant_live/. Toda vez que você substituir o arquivo por uma versão mais nova, os dados já refletem automaticamente — não precisa reiniciar o app. Não tem placar/vitória por partida nesse formato (só a média de cada jogador no campeonato), então aqui só dá pra ver a tabela de jogadores por mapa, sem Win Rate. A coluna "Agentes" mostra só as porcentagens de pick, sem o nome de cada agente (isso se perde ao copiar a tabela do site de origem).
